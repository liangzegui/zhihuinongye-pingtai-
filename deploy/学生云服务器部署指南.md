# 学生云服务器部署指南

## 📋 部署概览

一台服务器搞定所有内容：
- ✅ MySQL 8 数据库
- ✅ Spring Boot 后端（8080端口）
- ✅ Vue 前端（80端口，Nginx托管）
- ✅ 华为云IoTDA数据接收

---

## 第一步：购买学生云服务器

### 推荐配置

| 平台 | 价格 | 配置 | 购买链接 |
|------|------|------|---------|
| 阿里云 | 9.9元/月 | 2核2G | https://developer.aliyun.com/plan/student |
| 腾讯云 | 10元/月 | 2核2G | https://cloud.tencent.com/act/campus |
| 华为云 | 9元/月 | 1核2G | https://developer.huaweicloud.com/campus |

### 购买时注意

1. **操作系统**：选择 **CentOS 7/8** 或 **Ubuntu 20.04/22.04**
2. **带宽**：至少 1Mbps
3. **实名认证**：需要学生认证
4. **安全组**：开放端口 **22（SSH）、80（HTTP）、8080（后端）**

---

## 第二步：配置安全组

### 阿里云配置步骤

1. 进入 **云服务器ECS** → **实例**
2. 点击您的实例 → **安全组** → **配置规则**
3. 添加入方向规则：

| 端口 | 协议 | 授权对象 | 说明 |
|------|------|---------|------|
| 22 | TCP | 0.0.0.0/0 | SSH登录 |
| 80 | TCP | 0.0.0.0/0 | 前端访问 |
| 8080 | TCP | 0.0.0.0/0 | 后端API |
| 3306 | TCP | 127.0.0.1/32 | MySQL（仅本机） |

### 腾讯云/华为云

类似步骤，在防火墙/安全组中添加相同规则。

## 第三步：连接服务器

### Windows用户

1. 下载并安装 **MobaXterm** 或 **PuTTY**
2. 或使用PowerShell：

```powershell
ssh root@您的服务器IP
```

### 获取服务器IP

在云服务器控制台的实例列表中查看 **公网IP**

---

## 第四步：一键部署

### 4.1 上传部署脚本

连接服务器后，执行：

```bash
# 创建目录
mkdir -p /opt/deploy

# 下载部署脚本（从您的GitHub仓库）
curl -O https://raw.githubusercontent.com/liangzegui/zhihuinongye-pingtai-/appmod/java-upgrade-20251226125202/deploy/deploy.sh

# 或者手动上传 deploy.sh 文件到服务器
```

### 4.2 修改配置（可选）

如果需要修改数据库密码等，编辑脚本：

```bash
vi deploy.sh
```

修改以下配置：

```bash
MYSQL_ROOT_PASSWORD="Agri@2024"        # MySQL root密码
MYSQL_DB_NAME="agri_db"                # 数据库名
MYSQL_DB_USER="agri_user"              # 数据库用户名
MYSQL_DB_PASSWORD="Agri@123456"        # 数据库密码
```

### 4.3 执行部署

```bash
# 添加执行权限
chmod +x deploy.sh

# 开始部署（约10-15分钟）
./deploy.sh
```

部署过程会自动：
1. 安装 JDK 21
2. 安装 Maven
3. 安装 Node.js
4. 安装 MySQL 8
5. 安装 Nginx
6. 克隆代码并构建
7. 创建系统服务
8. 初始化数据库

## 第五步：验证部署

### 5.1 检查服务状态

```bash
# 检查后端服务
systemctl status agri-backend

# 检查Nginx
systemctl status nginx

# 检查MySQL
systemctl status mysql
```

所有服务应该显示 **active (running)**

### 5.2 访问系统

在浏览器中访问：

```
http://您的服务器公网IP
```

应该能看到登录页面。

测试账号：
- 用户名：`admin`
- 密码：`123456`

### 5.3 测试后端API

```bash
curl http://您的服务器IP:8080/api/iotda/health
```

应返回：
```json
{"code":200,"message":"success","data":"IoTDA Webhook服务正常运行"}
```

## 第六步：配置华为云IoTDA

### 6.1 更新数据转发规则

1. 登录 [华为云IoTDA控制台](https://console.huaweicloud.com/iotdm/)
2. 进入 **规则** → **数据转发**
3. 创建或编辑规则：

| 配置项 | 值 |
|--------|-----|
| 规则名称 | `forward_sensor_data` |
| 触发事件 | **设备属性上报** |
| 转发类型 | **HTTP推送** |
| **URL** | `http://您的服务器IP:8080/api/iotda/webhook` |

例如：`http://123.45.67.89:8080/api/iotda/webhook`

### 6.2 启用规则

点击 **启用** 激活规则

## 常用命令

### 服务管理

```bash
# 后端服务
systemctl start agri-backend      # 启动
systemctl stop agri-backend       # 停止
systemctl restart agri-backend    # 重启
systemctl status agri-backend     # 状态
journalctl -u agri-backend -f     # 查看日志

# Nginx
systemctl restart nginx
systemctl status nginx

# MySQL
systemctl restart mysql
systemctl status mysql
```

### 查看日志

```bash
# 后端日志（实时）
journalctl -u agri-backend -f

# Nginx访问日志
tail -f /var/log/nginx/access.log

# Nginx错误日志
tail -f /var/log/nginx/error.log
```

### 数据库操作

```bash
# 登录MySQL
mysql -uagri_user -pAgri@123456 agri_db

# 查看数据
SELECT * FROM t_env_data ORDER BY collect_time DESC LIMIT 10;
```

## 更新项目

如果代码有更新，重新部署：

```bash
# 停止后端服务
systemctl stop agri-backend

# 拉取最新代码
cd /opt/agri-project
git pull

# 重新构建后端
cd idea/agri-backend
mvn clean package -DskipTests

# 重新构建前端
cd /opt/agri-project/vue/agri-frontend
npm run build
cp -r dist/* /usr/share/nginx/html/

# 启动服务
systemctl start agri-backend
systemctl restart nginx
```

## 故障排查

### 问题1：无法访问前端

```bash
# 检查Nginx状态
systemctl status nginx

# 检查80端口是否开放
netstat -tlnp | grep 80

# 查看Nginx错误日志
tail -f /var/log/nginx/error.log
```

### 问题2：后端服务启动失败

```bash
# 查看后端日志
journalctl -u agri-backend -n 50

# 检查8080端口
netstat -tlnp | grep 8080

# 检查数据库连接
mysql -uagri_user -pAgri@123456 agri_db
```

### 问题3：IoTDA数据无法接收

```bash
# 查看后端实时日志

  -H "Content-Type: application/json" \
  -d '{"notify_data":{"body":{"services":[{"service_id":"default","properties":{"temp":25.5}}]}}}'
```

## 性能优化

### 调整JVM内存（1G服务器）

编辑后端服务配置：

```bash
vi /etc/systemd/system/agri-backend.service
```

修改 ExecStart 行：

```
ExecStart=/usr/bin/java -Xms256m -Xmx512m -jar -Dspring.profiles.active=prod target/agri-backend-0.0.1-SNAPSHOT.jar
```

重新加载并重启：

```bash
systemctl daemon-reload
systemctl restart agri-backend
```

## 安全建议

1. **修改默认密码**：部署后立即修改所有默认密码
2. **定期备份数据库**：
   ```bash
   mysqldump -uagri_user -pAgri@123456 agri_db > backup_$(date +%Y%m%d).sql
   ```
3. **开启防火墙**：
   ```bash
   firewall-cmd --permanent --add-port=80/tcp
   firewall-cmd --permanent --add-port=8080/tcp
   firewall-cmd --reload
   ```
